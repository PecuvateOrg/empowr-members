## Configuration and release

- Use the existing Honor Oak Community Centre venue record; verify its identity before creating a duplicate venue.
- Use Europe/London for date entry and display. These dates fall after the October clock change: 09:30–14:30 local corresponds to 09:30–14:30 UTC.
- Set the offering's standard price to 4500 pence, early-bird price to 4000 pence and walk-in price to 5000 pence through the existing admin configuration.
- Set each occurrence's capacity to 25 and early-bird allocation to 5 through the existing admin controls. Check for matching occurrences first to avoid duplicates.
- Scope any shared offering-price changes carefully: verify other dates under the same offering before updating its prices.
- Standard online bookings include the early-bird ticket tier: both online price tiers must collect the required equipment choice for every child.
- After the equipment database prerequisite, deployment and test-payment verification, make these dates available on the public camp page.
- Verify each date is independently bookable, early-bird eligibility falls back to the standard ticket once the five places are taken, and paid children appear in the correct session's equipment list and existing check-in register.
- Keep exact remaining ticket counts off the public page, consistent with the existing ticket-display behaviour. Admin capacity information remains available.

This document does not create sessions or publish availability. Pecuvate must apply the above configuration as part of the rollout.
